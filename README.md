# Alt Detector

Scans a Windows PC for Minecraft and Discord accounts and syncs them to the
ban-evasion server, so alts on one machine are visible. Based on Siege's
`accounts` module.

It reads Minecraft launcher data and Discord session data across the Windows
profiles on the machine and sends account IDs plus hashed hardware signals to the
server. It never sends the Discord token or email. Run it only on a machine whose
owner agreed to the scan.
