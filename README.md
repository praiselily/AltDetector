

Scans a Windows PC for Minecraft and Discord accounts and looks for
past checks that took place on a pc, so deleted alts on one are visible. Based on Siege's
`accounts` module.

It parses minecraft accounts played and configured across all major game clients with a few outliers. (modrinth
and a few other ones i didnt know off) Works pretty basic through set regex for usernames and game chat logs.

Everything works synced with siege so if you scan a player with it, the accounts will be remembered for the next time
regardless if they made attempts to alt-evade.

Note: The tool is intentionally a bit more on the invasive side, and should only be used on players that has consented
